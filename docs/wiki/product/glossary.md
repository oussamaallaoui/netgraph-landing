# Glossary

UI terms are in French, as they appear in the product.

| Term | Meaning |
| --- | --- |
| **Contact** | A person the user imported from one of their sources. Belongs to that user only. |
| **Source** | Where contacts come from: Téléphone, LinkedIn, Instagram, Excel/CSV. |
| **Demande** (request) | What the user is looking for, written as an infinitive phrase: "Trouver ma prochaine mission de conseil en finance". |
| **1er degré** (first degree) | A direct contact of the user. |
| **2e degré** (second degree) | A contact of one of the user's contacts. Only visible when the connecting contact is a NetGraph user who opted in. |
| **Chemin** (path) | The chain from the user to the person who can help: *Vous → Sara → Jérôme*. |
| **Introducteur** (introducer) | The contact in the middle of a path who can make the introduction ("Sara peut vous présenter"). |
| **Force du lien** (link strength) | A 0–100 score of how strong a relationship is, based mainly on how often and how recently the two people interact. |
| **Score d'une piste** | How promising a person is for a request, combining relevance and the link strength along the path. |
| **Agent** | The part of NetGraph that suggests who to contact and when, and drafts the message. It never sends anything itself. |
| **Brouillon** (draft) | A message prepared by the agent, which the user can edit and send. |
| **Rythme d'échange** | How often the user usually talks to a contact ("tous les 10 jours en moyenne"). A relationship going quiet compared to its rhythm triggers a suggestion. |
| **Beta** | The free early-access programme: the first 100 signups get 3 months free. |
